# CondoLink 서비스 유사도·우수 관행 분석

분석 시각: 2026-08-20T04:36:31Z  
범위: 현재 열린 `콘도링크` 프로젝트와 공개 URL의 읽기 전용 확인만 사용. 코드, 설정, Git 이력, 배포는 변경하지 않았다.

## 1. 서비스 판정

CondoLink는 태국 콘도·임대 후보를 찾고 비교하며, 확인 항목을 기기에 보관하고 한국어·영어·태국어 문의 초안을 만드는 **임대 부동산 탐색·의사결정 보조 서비스**로 보인다. 코드의 문의문에는 예약이나 결제를 요청하는 문장이 아니라고 명시돼 있으므로, 현재 근거만으로는 거래 플랫폼·결제 서비스·임대관리 시스템으로 분류하지 않는다.

가장 가까운 내장 카탈로그 분류는 **121 부동산 검색(property search, 유사도 0.90)** 이다. 보조 분류는 **122 임대 관리(0.58)**, **123 단기 숙박(0.42)** 이다. 자세한 기준은 `similarity-candidates.json`에 기록했다.

## 2. 확인한 프로젝트 근거

| 관찰 항목 | 사실 근거 | 해석 |
|---|---|---|
| 후보 탐색·비교 | `20_SRC/full/app.js`의 후보, 필터, 비교 제어 | 핵심 탐색 여정이 존재한다. |
| 비용·조건 확인 | 같은 파일의 `stayCosts`, `stayConditions`, 계약/광고 숫자 대조 | 사용자의 현장 확인을 돕는다. |
| 3개 언어 문의문 | `generateInquiry()` | 다국어 문의 준비가 차별점이다. |
| 로컬 저장 | `persist()`/`restore()`의 `localStorage`, PWA 자산 | 입력값은 기기 중심으로 보관된다. |
| 안전 안내 | 선입금·무계약·신분증·오프플랫폼 위험 문구 | 거래 실행을 대신하지 않고 위험 신호를 알려 준다. |
| 자동 검사 자산 | `40_TESTS` 아래 PC·접근성·오프라인·모바일 검사 파일 | 검사 설계는 존재한다. 이번 분석에서 재실행하지는 않았다. |

공개 URL은 메인과 대시보드가 HTTP 200이었다. `https://hanksleekorea-boop.github.io/condolink/m/`는 HTTP 404이었다. 이는 별도 모바일 경로의 공개 상태이며, 메인 화면의 반응형 작동 여부와는 별개다.

## 3. 외부 서비스의 실제 관행과 비교

Hipflat의 [공식 태국 임대 목록](https://www.hipflat.co.th/en/property-for-rent)과 [공식 홈](https://www.hipflat.co.th/en)은 지역·매물 유형별 탐색, 대규모 임대 목록, 조건 필터라는 시장형 탐색의 기준을 보여 준다. CondoLink는 그 규모·실시간 재고를 검증할 근거는 없지만, 매물 자체를 복제하기보다 사용자가 확인해야 할 비용·계약·입주 조건을 구조화하는 쪽에 강점이 있다.

Airbnb의 [숙소 선택 안전 안내](https://www.airbnb.com/help/article/241)는 상세 설명, 후기, 안전 정보, 플랫폼 안의 메시지와 결제를 강조한다. 이 중 CondoLink에 바로 이식할 수 있는 것은 "정보 최신일", "출처", "확인 주체", "안전한 문의 경로"의 표시다. 반면 신원확인·예약 심사·결제보호·24시간 안전지원은 운영 조직과 법적 설계가 필요한 거래 플랫폼 기능이므로, 현재 제품에 있다고 암시하면 안 된다.

## 4. 잘 맞는 우수 관행

1. **매물 사실과 사용자 희망을 분리한다.** CondoLink는 문의문에서 사용자가 선택한 생활 조건을 매물 사실로 단정하지 말라고 한다. 이 경계를 모든 후보 카드에도 유지한다.
2. **확인일과 출처를 의사결정의 일부로 만든다.** 가격만 비교하지 말고 “누가, 언제, 어떤 원천에서 확인했는지”를 같은 무게로 표시한다.
3. **비용을 총액 관점으로 본다.** 월세/일세, 보증금, 청소·입실비, 관리비·공과금을 분리하고 누락값은 추정하지 않는다.
4. **문의는 초안으로만 제공한다.** 보내기·결제·계약으로 오해되지 않도록 현재의 문구 경계를 유지한다.
5. **현지 위험 안내를 행동으로 연결한다.** 선입금, 서면 계약 부재, 여권 원본 요구, 외부 송금 압박마다 “확인할 증거”와 “중단 기준”을 제시한다.
6. **로컬 우선 개인정보 모델을 명확히 설명한다.** 기기 초기화·브라우저 데이터 삭제·내보내기·복원 실패 시의 결과를 화면과 정책에 일치시킨다.

## 5. 우선 개선 과제

| 우선순위 | 무엇을 | 왜 | 예상 효과 | 검증 방법 |
|---:|---|---|---|---|
| 1 | 별도 `/m/` 링크·QR·문서의 실제 진입 경로를 통일 | 공개 모바일 주소가 404 | 유입 손실과 신뢰 저하 방지 | HTTP 검사와 실제 좁은 화면 열기 |
| 2 | 후보별 출처·확인자·확인일·만료 상태를 필수 표기 | 현지 매물 정보의 최신성은 핵심 | 잘못된 문의·방문 감소 | 테스트 데이터와 오래된 데이터의 UI 확인 |
| 3 | “문의 초안, 거래 아님” 경계를 카드·공유 화면에도 반복 | 결제·계약 기능으로 오해할 위험 | 소비자 오해 감소 | 콘텐츠 검토와 사용자 과업 시험 |
| 4 | 저장 위치·삭제·내보내기 안내를 하나의 개인정보 문서로 정리 | 로컬 저장은 사용자에게도 명확해야 함 | 신뢰·지원 비용 개선 | 브라우저 데이터 삭제와 문서 대조 |
| 5 | 공개 릴리스 버전·검사 시각·변경 내역을 메인과 대시보드에 연결 | 현재 폴더에는 역사적 기록이 섞여 있음 | 지원·재현성 개선 | URL, 소스 버전, 검사 결과 상호 대조 |
| 6 | 모바일 실제 기기 시험을 최소 1대에서 수행 | 자동 검사만으로 입력·설치·오프라인을 보증 못 함 | 출시 위험 감소 | 설치, 재실행, 오프라인, 좁은 폭 과업 기록 |
| 7 | 외부 데이터/중개인 연동 전에는 "미연동" 상태를 명확히 유지 | 현재 공개 AI/OCR/지도/푸시 등이 연결 필요로 표시됨 | 잘못된 기대 방지 | 비연동 상태 UI 회귀 검사 |

## 6. 미확인과 한계

- 실제 Android 기기 시험: **미실시**. 이번 분석 환경에서는 연결된 기기를 사용하지 않았다.
- 현재 Git 작업 트리: 기존 worktree 메타데이터가 끊어져 정상 `git status` 결과를 확보하지 못했다. 이를 복구하거나 수정하지 않았다.
- 운영자 신원, 중개 권한, 고객지원, 결제·환불·계약 정책, 법률 적합성, 실시간 매물 품질: **미확인**.
- 로컬 자동 검사 파일은 존재하지만, 이번 분석은 대상 제품과 그 밖의 파일을 바꾸지 않는 범위라 재실행하지 않았다. 따라서 “자동 검사 통과”라고 판정하지 않는다.
- 요청된 외부 분석 엔진은 로컬에서 발견되지 않았다. 검토되지 않은 원격 실행 파일을 실행하지 않았으며, `engine-attempt.json`에 이유를 기록했다. 그러므로 엔진 기반 준비도 점수는 산출하지 않았다.

## 7. 결론

CondoLink는 “태국 임대 후보를 안전하게 확인하고 다국어 문의를 준비하는 개인용 의사결정 보조”로 포지셔닝할 때 가장 일관된다. 대형 부동산 포털과의 경쟁점은 실시간 매물량이 아니라, 출처·신선도·총비용·현장 확인·다국어 질문을 한 흐름에 묶는 신뢰도다. 다음 단계의 가장 큰 제품 리스크는 별도 모바일 URL의 404와, 실시간 매물/운영 기능의 범위를 사용자가 오해할 수 있다는 점이다.
